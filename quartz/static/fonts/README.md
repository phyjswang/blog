# Bundled typefaces

The WOFF2 faces are extracted without modification from the installed
[TufteObsidian](https://github.com/pleiadesm/TufteObsidian) theme:

- `tufte-0.woff2`: ET Book roman
- `tufte-1.woff2`: ET Book italic
- `tufte-2.woff2`: ET Book bold
- `tufte-3.woff2`: Cabin variable, Latin
- `tufte-4.woff2`: Cabin variable, Latin extended

Schwartz, distributed under the MIT license (`LICENSE-et-book`). Cabin is
